# Contributing

Thanks for considering a contribution. Patterns here are first-party: each is verified against
current documentation before it is published, so proposals are welcome as issues (the topic, the
problem it solves for an agent, and the sources), and corrections to a published pattern as
issues or pull requests that cite their source.

## Reporting issues

- **Bugs / feature requests:** open a GitHub issue with repro steps (the pattern, what an agent did with it, and the source that contradicts it).
- **Security issues:** please do NOT open a public issue. Email security@pathrule.io instead
  (see [SECURITY.md](SECURITY.md)).
